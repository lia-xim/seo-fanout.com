# SEO Fan-out Explorer — project brief

## Accepted purpose

Build a standalone free practitioner tool that turns one keyword, topic, or page question into a bounded map of user goals, relevant subtopics, source roles, evidence gaps, and one defensible page priority. The complete useful result is available without signup.

## Product contract

The tool is deterministic and browser-local. It does not call a model, search provider, analytics service, or paid API and never claims access to hidden queries or reasoning. It chooses exactly one outcome: strengthen, consolidate, create one page, create an evidence asset first, or take no page action.

The project is not the AI-Fanout Evidence Lab. Its optional browser-local comparison accepts user-pasted visible text for one-off structural measures only. Provider retrieval, monitoring, longitudinal evidence, factual scoring, and hidden-process inference remain outside this site's scope.

- Indexing requires explicit launch approval.
- Validate the decision framework against at least ten real page inventories.
- Publish three real decision cases or clearly retain the case register as pending.
- Name the quarterly content owner and correction SLA.
- Recheck routes, status codes, canonicals, sitemap, links, keyboard path, mobile state, exports, apex and www after every production change.
